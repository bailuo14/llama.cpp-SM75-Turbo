# 🚀 llama.cpp-SM75-Turbo

> **为 NVIDIA Turing (SM75) 架构优化

市面上的 `llama.cpp` 通用版为了兼容从 Pascal 到 Hopper 的所有显卡，代码中包含了大量冗余逻辑。
本项目**大刀阔斧地做了减法**，仅保留针对 **Turing 架构 (RTX 2060/2070/2080/Ti/Super)** 的核心计算内核

- **⚡ 极速推理**：剔除冗余代码，计算效率提升显著，2080ti22G运行Qwen3.8-27B-GSQ-ROC-IQ3_XXS稳定30 tk/s+
- **🪶 极致轻量**：核心引擎体积极小，无多余依赖，老旧电脑也能轻松运行。
- **系统**: Windows 10 (64-bit)
- 理论上所有SM75（也就是图灵架构）的显卡都能跑
- 
> **⚠️ 注意**：速度受 CPU 内存带宽、后台程序占用影响较大,所以不一定能达到我的速度
